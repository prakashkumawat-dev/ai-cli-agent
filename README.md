# Kelvin Code

**Kelvin Code** is an open-source AI CLI coding agent powered by **Google Gemini**. It helps developers **build websites, debug code, learn programming, and work with their codebase directly from the terminal**.

Kelvin comes with powerful tools for **file-system operations, command execution, web searching, web scraping, and web crawling**. It can also install and work with external npm packages when needed.

## ✨ Features

- 🤖 AI-powered coding agent using Google Gemini
- 💻 Build websites and applications from the terminal
- 🐛 Debug and understand existing code
- 📚 Learn programming with an interactive AI agent
- 📁 File-system tools for reading, creating, and modifying files
- ⚡ Execute terminal commands
- 📦 Install and use external npm packages
- 🔎 Web searching with Tavily
- 🕷️ Web scraping
- 🌐 Web crawling
- 🔓 Fully open source
